# Windsurf Project Rules: Java 25 & Spring Boot 4.x

<communication>
- ALWAYS respond, explain, and converse with the user in **Russian** (на русском языке).
- Code comments and documentation should be in English.
</communication>

<tech_stack>
- Language: Java 25 (utilize modern features: Virtual Threads, Pattern Matching, Records, Scoped Values where appropriate).
- Framework: Spring Boot 4.x (adhere to Jakarta EE standards).
- Testing: JUnit 5, Mockito, Spring Boot Test, AssertJ.
</tech_stack>

<coding_standards>
- Write clean code adhering to SOLID and DRY principles.
- Use Java Records for DTOs.
- Always use constructor injection instead of field-level `@Autowired`.
- Implement validation using `jakarta.validation.constraints`.
</coding_standards>

<spring_boot_specifcs>
- Prefer `@ConfigurationProperties` over `@Value`.
- Utilize built-in Virtual Threads support (`spring.threads.virtual.enabled=true`).
</spring_boot_specifcs>

<testing_rules>
- Write unit tests using **JUnit 5** and **Mockito**.
- Use `@ExtendWith(MockitoExtension.class)` for pure unit tests without starting the Spring context.
- Use `@WebMvcTest` or `@SpringBootTest` strictly for integration and slice testing.
- Follow the **Given-When-Then** (AAA - Arrange, Act, Assert) structure for all test cases.
- Use **AssertJ** (`assertThat`) for fluent and readable assertions.
- Mock all external dependencies and database layers in unit tests.
- Ensure test method names are descriptive (e.g., `shouldReturnUserWhenIdExists`).
</testing_rules>

<error_handling>
- Handle exceptions globally via `@ControllerAdvice` and `@ExceptionHandler`.
- Return errors matching the RFC 7807 (Problem Details) specification.
</error_handling>
